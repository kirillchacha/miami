# Miami — Miami Condo Kings Real Estate Landing Page

A fully responsive landing page for a luxury real estate agency specializing in new condominium developments in the Miami area, featuring a property gallery, client testimonials, and a modern UI.

## 🔗 Live Demo

[https://kirillchacha.github.io/miami/home.html](https://kirillchacha.github.io/miami/home.html)

## ✨ Features

- **Hero section** — bold intro highlighting the agency's experience and market leadership since 2003
- **About section** — company background, 50+ years of industry experience, and multiple industry awards (2010, 2011, 2013)
- **Property gallery** — showcase of premium condo developments (Marina Palms, Edition Residences, Faena House) with images and descriptions
- **Testimonials** — client endorsements with profile photos for social proof
- **Contact section** — phone, email, and physical address for direct inquiries
- **Responsive navigation** — sticky header linking to Home, About Us, Gallery, Testimonials, and Contacts
- **Fully responsive design** — optimized layout for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **HTML5** — semantic markup for structure and SEO
- **CSS** — custom styling for layout, typography, and responsiveness
- **JavaScript** — interactivity and dynamic UI behavior
- **Custom fonts & icons** — for a polished, on-brand visual style

## 🚀 Getting Started

No build tools or installation required — this is a static site.

1. Clone the repository:
   ```bash
   git clone https://github.com/kirillchacha/miami.git
   ```
2. Open `home.html` (or `index.html`) directly in your browser, or serve the folder with any static file server.
